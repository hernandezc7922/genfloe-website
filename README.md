# GenFloe Website

The homepage for **GenFloe — Small Business Growth Solutions**.

The whole site is a single self-contained file, `index.html`. The logo and images are embedded in it and fonts load from Google Fonts, so it needs no build step.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. In the repository on GitHub, go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Pick the `main` branch and the `/ (root)` folder, then click **Save**.

GitHub shows the live address on that page after a minute or two. To use `genfloe.com`, add it under **Custom domain** on the same page and point your domain's DNS at GitHub Pages.

## Before launch

- Add Privacy Policy and Terms of Service pages. The footer links are placeholders.
- Confirm that the stock photo in "The GenFloe Approach" is licensed for commercial use, or replace it with the founder portrait.
